4R snippets

Assumes a data frame df with outcome y and factor group. Repeated-measures data must be in long format.

t-tests t-test
# Welch (default): allows unequal variances
t.test(y ~ group, data = df)

# Pooled: assumes equal variances
t.test(y ~ group, data = df, var.equal = TRUE)

# Paired: same subjects measured twice
t.test(df$before, df$after, paired = TRUE)

# Same thing: one-sample t on the differences
t.test(df$after - df$before)
ANOVA + post hoc ANOVA
fit <- aov(y ~ group, data = df)
summary(fit)
TukeyHSD(fit)                       # pairwise, familywise-adjusted

oneway.test(y ~ group, data = df)   # Welch ANOVA (unequal variances)
kruskal.test(y ~ group, data = df)  # rank-based alternative

# Repeated measures (long format; id and cond are factors)
summary(aov(y ~ cond + Error(id/cond), data = long))
MANOVA MANOVA
fit <- manova(cbind(y1, y2, y3) ~ group, data = df)
summary(fit)                   # Pillai's trace (default)
summary(fit, test = "Wilks")   # alternative statistic
summary.aov(fit)               # follow-up: one ANOVA per outcome

# Assumption checks
mvnormtest::mshapiro.test(t(as.matrix(df[, c("y1","y2","y3")])))
biotools::boxM(df[, c("y1","y2","y3")], df$group)
Permutation test (2 groups) nonparametric
set.seed(1)
obs  <- diff(tapply(df$y, df$group, mean))   # observed difference

perm <- replicate(10000, {
  g <- sample(df$group)                      # shuffle labels
  diff(tapply(df$y, g, mean))
})

# Two-sided p-value (+1 so p is never exactly 0)
(sum(abs(perm) >= abs(obs)) + 1) / (10000 + 1)
hist(perm); abline(v = c(obs, -obs), col = "red")
Rank tests: 2 groups / paired nonparametric
# Two independent groups (Mann-Whitney U)
wilcox.test(y ~ group, data = df)
wilcox.test(y ~ group, data = df, conf.int = TRUE)  # shift CI
# many ties? add exact = FALSE

# Paired / one-sample: Wilcoxon signed-rank
wilcox.test(df$before, df$after, paired = TRUE)

# Sign test (fewest assumptions, lowest power)
d <- df$after - df$before
binom.test(sum(d > 0), sum(d != 0))
Rank tests: 3+ groups, association, counts nonparametric
# 3+ independent groups
kruskal.test(y ~ group, data = df)
FSA::dunnTest(y ~ group, data = df, method = "holm")
pairwise.wilcox.test(df$y, df$group, p.adjust.method = "holm")

# 3+ related conditions (m: rows = subjects, cols = conditions)
friedman.test(as.matrix(m))

# Association (monotone, outlier-robust)
cor.test(x, y, method = "spearman")
cor.test(x, y, method = "kendall")

# Small 2x2 table (expected counts < 5)

fit <- aov(y ~ group, data = df)

5Key concepts

What "parametric" means

The test assumes the data come from a known shape (usually the normal bell curve) described by a few numbers called parameters: the mean μ and variance σ². t-test, ANOVA, MANOVA and Pearson correlation are parametric. Most powerful when the shape assumption holds.

What "nonparametric" means

No shape assumed. The test uses ranks (position when sorted) or signs (+/−) instead of raw values, so outliers and skew matter less and ordinal data work. Many are distribution-free: the null distribution is the same for any continuous data. A bit less powerful when data really are normal.

Distribution-free ≠ assumption-free

Rank tests still need independent observations and a meaningful order. Ties get midranks: 105 120 120 121 → 1 2.5 2.5 4. To read a result as a difference in medians or a shift, groups must have similar shapes (rank-sum) or symmetric differences (signed-rank).

Nonparametric tests don't test normality

They replace the normality assumption; they do not check it. Check normality with Q-Q plots (and Shapiro-Wilk as a rough guide), then choose.

Why not just mean − mean?

A raw difference has no scale. The test statistic is (difference) / (standard error): how many standard errors apart the means are, which accounts for spread and sample size.

Why not run many t-tests?

Each test carries a 5% false-positive risk, and they add up. 4 groups → 6 pairwise tests → familywise error 1 − 0.95⁶ ≈ 26%. ANOVA tests all groups at once at 5%; Tukey keeps pairwise follow-ups adjusted.

For 2 groups, F = t²

One-way ANOVA with 2 groups gives the same p-value as the pooled t-test, with F = t². (Welch's t differs slightly.)

Paired = one-sample t on differences

Each subject has 2 measurements. Compute d = after − before per subject, then test whether mean(d) = 0 with a one-sample t-test (df = n − 1).

Reading the p-value

If there were truly no effect, p is the chance of a result at least this extreme. It is not the probability the null is true, and it says nothing about effect size. Always report the estimate and confidence interval too.
